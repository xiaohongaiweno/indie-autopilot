# Google 索引诊断

诊断网站的 Google 索引和搜索表现问题。核心问题：Google 能爬取和索引你的页面吗？有什么技术问题阻止排名？

## 铁律

1. **不承诺排名。** SEO 是长期工作，不能保证具体排名。
2. **数据驱动。** 基于 Search Console 和实际数据诊断，不是猜测。
3. **优先级修复。** 先修复影响最大的问题，不要追求完美。
4. **质量 > 数量。** 有意义的修复胜过批量生成薄页面。
5. **持续监控。** SEO 问题会反复出现，需要持续监控。

## 诊断框架

### 1. 索引状态
- **已索引页面**：Google 知道哪些页面？
- **未索引页面**：哪些页面没被索引？为什么？
- **索引错误**：有软 404、重定向错误等？
- **规范 URL**：Google 认为的规范 URL 是什么？

### 2. 爬取状态
- **爬取预算**：Google 每天爬取多少页面？
- **爬取错误**：有 5xx、4xx 错误？
- **爬取延迟**：页面加载速度？
- **robots.txt**：是否正确配置？
- **sitemap**：是否提交且有效？

### 3. 搜索表现
- **总点击和展示**：整体搜索表现
- **关键词排名**：哪些关键词在排名？
- **平均位置**：排名位置趋势？
- **点击率**：CTR 是否健康？

### 4. 技术问题
- **移动友好性**：移动端体验？
- **核心 Web 指标**：LCP、FID、CLS？
- **HTTPS**：是否全站 HTTPS？
- **结构化数据**：是否使用 schema？
- **内部链接**：链接结构是否合理？

## 工作流程

### 1. 收集数据
- **Google Search Console**：
  - 效果报告（点击、展示、排名）
  - 索引报告（已索引、未索引、错误）
  - 爬取报告（爬取统计、错误）
  - 移动可用性和核心 Web 指标
- **网站检查**：
  - robots.txt
  - sitemap.xml
  - 页面源代码（meta tags、canonical、hreflang）
  - 页面速度

### 2. 诊断问题
**索引问题**：
- 页面未被索引的原因？
  - 被 robots.txt 阻止？
  - noindex 标签？
  - 规范 URL 不同？
  - 质量太低？
  - 重复内容？

**爬取问题**：
- 爬取错误的原因？
  - 服务器错误（5xx）？
  - 页面不存在（4xx）？
  - 访问被拒绝？
  - 爬取预算不足？

**排名问题**：
- 关键词排名低的原因？
  - 内容质量不够？
  - 技术 SEO 问题？
  - 反向链接不足？
  - 竞争激烈？

**性能问题**：
- 页面速度慢的原因？
  - 图片未优化？
  - 渲染阻止资源？
  - 服务器响应慢？
  - 未使用缓存？

### 3. 优先级排序
按影响和紧急程度排序：
- **P0（立即修复）**：阻止索引或严重影响排名
  - 服务器错误
  - 索引阻止
  - 移动不友好
  - 严重性能问题
- **P1（本周修复）**：显著影响排名
  - 爬取错误
  - 缺失 meta tags
  - 结构化数据问题
  - 内部链接问题
- **P2（本月修复）**：优化项
  - 内容优化
  - 性能优化
  - 反向链接建设

### 4. 修复建议
对每个问题：
- 问题描述
- 影响范围
- 修复步骤
- 验证方法
- 预期效果

### 5. 监控和验证
- 修复后提交重新索引
- 监控索引状态变化
- 跟踪排名变化
- 验证修复效果

## 常见问题和解决方案

### 页面未被索引
**原因**：
- 新页面，Google 还不知道
- 被 robots.txt 阻止
- noindex 标签
- 质量太低
- 重复内容

**解决方案**：
- 提交到 Search Console
- 检查 robots.txt
- 移除 noindex
- 提升内容质量
- 设置规范 URL

### 排名下降
**原因**：
- 算法更新
- 竞品超越
- 内容过时
- 技术问题
- 反向链接丢失

**解决方案**：
- 检查算法更新
- 分析竞品变化
- 更新内容
- 修复技术问题
- 建设反向链接

### 爬取错误
**原因**：
- 服务器不稳定
- URL 结构问题
- 重定向链
- 死链接

**解决方案**：
- 优化服务器性能
- 简化 URL 结构
- 修复重定向
- 更新死链接
