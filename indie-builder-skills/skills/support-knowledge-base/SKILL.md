# 支持知识库

构建产品支持文档和自助服务资源。核心问题：用户常见问题是什么？如何减少支持工单？如何让用户自助解决问题？

## 铁律

1. **用户优先。** 文档为用户服务，不是为开发者服务。
2. **搜索友好。** 用户能通过搜索找到答案。
3. **保持更新。** 过时的文档比没有文档更糟。
4. **简单清晰。** 用简单的语言解释清楚。
5. **预防为主。** 好的文档能预防问题，不只是解决问题。

## 知识库结构

### 帮助中心
- **快速开始**：新用户指南
- **常见问题**：FAQ
- **教程**：如何使用功能
- **故障排除**：解决常见问题
- **API 文档**：开发者文档（如果有）

### 文档类型
- **入门指南**：快速上手
- **功能教程**：如何使用特定功能
- **最佳实践**：如何用好产品
- **故障排除**：解决常见问题
- **API 文档**：技术文档
- **更新日志**：产品更新记录

## 工作流程

### 1. 识别需求
- 分析支持工单（高频问题）
- 收集用户反馈
- 审查用户行为数据
- 识别知识缺口

### 2. 规划内容
- 优先级排序（高频问题优先）
- 确定文档类型
- 设计文档结构
- 制定写作计划

### 3. 编写文档
- 用用户语言写
- 提供具体例子
- 添加截图和视频
- 测试文档准确性

### 4. 发布和维护
- 发布到帮助中心
- 设置搜索优化
- 收集用户反馈
- 定期更新

### 5. 监控和改进
- 追踪文档使用数据
- 收集用户反馈
- 识别改进机会
- 持续优化

## 文档编写指南

### 标题
- 清晰、具体
- 包含关键词
- 用用户语言

### 内容结构
- **概述**：这段文档讲什么？
- **步骤**：如何完成任务？
- **例子**：具体例子
- **提示**：有用的提示
- **警告**：注意事项

### 语言风格
- 用"你"称呼用户
- 用主动语态
- 句子简短
- 避免技术术语（除非必要）

### 视觉元素
- 截图：展示界面
- 视频：演示复杂流程
- 图表：解释概念
- 代码块：展示代码示例

## 自助服务优化

### 搜索优化
- **关键词**：使用用户搜索的关键词
- **同义词**：包含同义词和变体
- **结构**：清晰的标题和子标题
- **元数据**：描述和标签

### 智能推荐
- **相关文章**：推荐相关文档
- **下一步**：建议下一步做什么
- **联系支持**：找不到答案时联系支持

### 反馈机制
- **有用吗？**：用户反馈文档是否有用
- **评论**：用户评论
- **建议**：用户建议改进

## 工具

### 知识库平台
- **Notion**：灵活、易用
- **GitBook**：开发者友好
- **Help Scout**：集成支持
- **Intercom**：集成消息
- **Zendesk**：企业级

### 文档工具
- **Markdown**：简单、版本控制
- **MkDocs / Docusaurus**：静态站点生成
- **GitBook**：在线编辑和发布

## 指标

### 使用指标
- **文档浏览量**：多少用户查看文档？
- **搜索成功率**：搜索能找到答案吗？
- **有用率**：用户觉得文档有用吗？

### 效果指标
- **支持工单减少**：文档是否减少了工单？
- **自助服务率**：多少问题自助解决？
- **用户满意度**：用户对文档满意吗？

## 与其他 Skill 的关系
