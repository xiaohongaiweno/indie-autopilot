# Product directory submission playbook

## Discovery and qualification
For every candidate, verify:
- Official website and current product submission URL
- Product categories accepted
- Free versus paid options and any hidden conditions
- Current review/moderation policy
- Required logo, screenshots, description, pricing, social links, and maker details
- Duplicate listing and outbound link policies
- Audience relevance and likely discovery value

Never invent a submission URL. Prefer official pages. Record the source URL and date checked. A directory's homepage is not necessarily its submission form.

## Platform-specific listing package
Prepare:
- Product name
- Short tagline (platform length limit verified first)
- 1–2 sentence description
- Longer description
- Category and tags
- Official URL and relevant deep link
- Pricing model, honestly described
- Logo/screenshot/video assets
- Founder/maker description if requested
- Support/contact URL
- Privacy/security details where relevant

## Tracker
Fields: platform, official URL, submission URL, audience fit, free status, requirements, rules, prepared copy path, submitted date, listing URL, status, evidence, next review date.

## Quality gate
Only label `Free verified` when a current source supports the claim. If unclear, use `Unknown — verify before submission`. Never imply a listing is approved until a public listing or platform confirmation exists.
