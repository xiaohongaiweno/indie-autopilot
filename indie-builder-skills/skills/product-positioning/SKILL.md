# 产品定位与差异化

回答三个问题：为谁解决什么问题？为什么选你而不是替代方案？一句话怎么说清楚？

## 铁律

1. **定位来自用户，不来自你。** 基于用户反馈和竞品分析，不是自己的偏好。
2. **具体 > 泛泛。** "帮独立开发者 30 分钟内做好落地页" 胜过 "帮开发者做更好的产品"。
3. **差异化必须可感知。** 用户能在一分钟内看出不同，否则不算差异化。
4. **不追求所有人。** 明确谁不是目标用户，比试图吸引所有人更有效。
5. **定位会演变。** 记录当前版本，随用户反馈调整。

## 定位框架

### 目标用户画像
- **谁**：角色、行业、规模、技术水平
- **场景**：什么时候需要？频率？
- **痛点**：当前最大的 1-2 个问题
- **替代方案**：现在怎么解决？为什么不够？
- **不是目标用户**：明确排除谁

### 价值主张画布
- **用户任务**：用户想完成什么？
- **痛点**：当前方案的麻烦
- **收益**：用户期望的结果
- **你的产品**：如何减轻痛点、创造收益
- **独特价值**：为什么选你？

### 差异化策略
选择一种主要差异化方向：
- **功能差异化**：做竞品没有的功能
- **体验差异化**：更简单、更快、更美观
- **定价差异化**：更便宜、更灵活、更透明
- **细分市场**：专注竞品忽视的细分人群
- **商业模式**：开源、一次性购买、按用量

### 消息层次
- **一句话定位**：为[谁]提供[什么]，不同于[替代]
- **价值主张**：3 个核心收益
- **支撑证据**：功能、数据、用户证言
- **社交证明**：用户数、评价、知名客户

## 工作流程

### 1. 输入收集
从其他 Skill 收集：
- `product-validation`：验证过的痛点和用户画像
- `competitor-intelligence`：竞品定位和差异化机会
- `customer-feedback-loop`：真实用户反馈

### 2. 定位草稿
填写定位模板：
```
为 [目标用户]
他们 [痛点/需求]
我们的产品是 [品类]
它能 [核心价值]
不同于 [竞品/替代]
我们的独特之处是 [差异化]
```

### 3. 验证定位
- 给 5 个目标用户看，能否一句话说清楚？
- 他们觉得有吸引力吗？
- 他们觉得可信吗？
- 他们会告诉朋友吗？

### 4. 消息层次
基于定位，构建：
- 网站标题和副标题
- 产品描述（一句话、一段话、一页）
- 销售话术（电梯演讲）
- 社交媒体 bio

### 5. 一致性检查
确保所有触点消息一致：
- 网站、落地页
- 产品内消息
- 营销材料
- 客服回复

## 与其他 Skill 的关系

- `product-validation`：验证通过 → 本 Skill 定位
- `competitor-intelligence`：提供竞品定位分析
- `product-ux-conversion`：定位指导 UX 和转化设计
- `content-marketing-engine`：定位指导内容方向
- `launch-campaign-planner`：定位指导发布消息
