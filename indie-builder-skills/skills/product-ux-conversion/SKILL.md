# 产品 UX 与转化设计

设计用户从发现到转化的完整体验。核心问题：用户如何完成目标？哪里会卡住？如何减少摩擦？

## 铁律

1. **用户目标优先。** 设计帮用户完成任务，不是展示功能。
2. **简单 > 复杂。** 能一步完成不要两步，能自动不要手动。
3. **转化来自信任。** 清晰的定价、真实的社交证明、透明的政策。
4. **移动优先。** 先设计移动端，再扩展桌面端。
5. **数据驱动。** 基于用户行为数据优化，不是个人偏好。

## 设计框架

### 用户流程地图
绘制关键流程：
- **发现流程**：首次访问 → 理解价值 → 决定试用
- **注册流程**：注册 → 验证 → 首次使用
- **核心流程**：完成主要任务的路径
- **付费流程**：了解定价 → 选择方案 → 付款
- **留存流程**：回访 → 完成价值 → 形成习惯

### 转化漏斗
每个阶段：
- **入口**：用户从哪来？
- **落地**：看到什么？
- **行动**：下一步是什么？
- **摩擦**：什么会阻止他们？
- **退出**：为什么离开？

### UX 原则
- **清晰**：用户知道自己在哪、能做什么
- **一致**：相同元素相同行为
- **反馈**：操作后有明确反馈
- **容错**：允许撤销，防止误操作
- **可访问**：键盘可操作，屏幕阅读器友好

### 转化优化
- **价值主张清晰**：一句话说清楚
- **CTA 明确**：按钮文字具体（"开始免费试用"而非"提交"）
- **社会证明**：用户数、评价、logo
- **减少表单**：只问必要信息
- **信任信号**：安全标识、退款保证、隐私政策

## 工作流程

### 1. 用户研究
从其他 Skill 收集：
- `product-positioning`：目标用户画像
- `customer-feedback-loop`：用户反馈和痛点
- `competitor-intelligence`：竞品 UX 分析

### 2. 用户流程设计
对每个关键流程：
- 绘制流程图
- 标注决策点
- 识别摩擦点
- 优化路径

### 3. 线框图设计
- 页面布局
- 核心元素位置
- 交互说明
- 移动端适配

### 4. 转化点优化
对每个转化点：
- CTA 位置和样式
- 表单字段优化
- 信任信号添加
- A/B 测试计划

### 5. 可用性测试
- 找 5 个目标用户
- 给任务让他们完成
- 观察卡点
- 收集反馈
- 迭代设计

### 6. 设计系统
建立基础设计系统：
- 颜色、字体、间距
- 组件库（按钮、表单、卡片）
- 交互模式
- 响应式规则

## 常见转化问题

- **注册摩擦**：要求太多信息、强制邮箱验证
- **定价困惑**：方案太多、价格不透明
- **信任缺失**：没有社交证明、没有联系方式
- **流程断裂**：步骤太多、页面跳转混乱
- **移动端体验差**：按钮太小、表单难填

## 与其他 Skill 的关系
