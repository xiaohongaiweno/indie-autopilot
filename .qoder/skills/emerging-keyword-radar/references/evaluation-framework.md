# 七维评估框架

## 评分标准

每个维度 0-10 分，总分 = 七维加权平均（默认等权，可根据项目调整）。

### 1. 新颖性（Novelty）

**问题**：这个词是以前就有的成熟词，还是新出现的？

| 分数 | 标准 |
|---|---|
| 8-10 | 过去 3 个月内首次出现或搜索量从零开始上升 |
| 5-7 | 原本存在但近期有新变体或新使用场景 |
| 2-4 | 成熟词，搜索模式稳定 |
| 0-1 | 完全成熟的红海词 |

**检查方法**：
- Google Trends 过去 5 年数据：是否一直存在？
- Wayback Machine：是否有网站早就在做这个话题？
- Autocomplete：是否是新的补全建议？

### 2. 增长性（Growth）

**问题**：是短期热点还是持续上升？

| 分数 | 标准 |
|---|---|
| 8-10 | 过去 6 个月持续上升，无下降迹象 |
| 5-7 | 过去 3 个月上升，但可能有周期性 |
| 2-4 | 短期脉冲（新闻事件驱动），预计回落 |
| 0-1 | 已经过了峰值，正在下降 |

**检查方法**：
- Google Trends 时间线：看 3 个月和 12 个月趋势
- 是否有多次上升（非单次脉冲）
- 相关词是否在扩散（从核心词扩展到周边词）

**衰减信号**：
- 半衰期 < 30 天：新闻驱动，不适合长期内容
- 季节性模式：每年固定时间上升，可以做但要等时机
- 一次性事件：产品发布、政策变化，窗口有限

### 3. 搜索意图（Search Intent）

**问题**：用户搜这个词时想做什么？

| 意图类型 | 示例 | 商业价值 |
|---|---|---|
| 信息类（Informational） | "what is X"、"how to Y" | 中（内容流量） |
| 比较类（Commercial） | "X vs Y"、"best X tool" | 高（转化意图） |
| 导航类（Navigational） | "X login"、"X pricing" | 低（已有品牌） |
| 任务类（Transactional） | "convert PDF to Word"、"compress image" | 高（工具需求） |

| 分数 | 标准 |
|---|---|
| 8-10 | 任务类或比较类意图，用户有明确行动需求 |
| 5-7 | 信息类意图，但有转化路径（教程 → 工具） |
| 2-4 | 纯信息类，难以转化 |
| 0-1 | 导航类，属于其他品牌 |

**检查方法**：
- 搜索结果前 5 个是什么类型的页面？
- People Also Ask 中的问题措辞
- Autocomplete 中的动词（how to, best, free, online）

### 4. 竞争度（Competition）

**问题**：搜索结果中是否已经有强势网站？

| 分数 | 标准 |
|---|---|
| 8-10 | 前 10 结果多为小站、论坛、低质量页面 |
| 5-7 | 有中等网站，但缺少专门的高质量页面 |
| 2-4 | 有权威网站占据，但内容不够深入 |
| 0-1 | 被大站（Wikipedia、G2、Capterra、大厂博客）完全占据 |

**检查方法**：
- 搜索结果前 10 的域名权威度（DA）
- 前 3 结果的页面质量：内容深度、用户体验、更新频率
- 是否有专门的工具页面或只是博客文章
- 搜索结果中是否有论坛帖子（说明缺专门内容）

**低竞争信号**：
- 搜索结果中有 Reddit/Quora 帖子排在前 5
- 现有页面内容浅、体验差、超过 2 年未更新
- 没有专门的工具页面，只有文字教程
- 搜索结果中有明显不相关的页面

### 5. 商业价值（Business Value）

**问题**：这个词背后有没有工具/产品/服务的切入点？

| 分数 | 标准 |
|---|---|
| 8-10 | 明确的产品需求：用户需要工具、自动化或 SaaS |
| 5-7 | 可以引流到付费产品（教程 → 高级功能） |
| 2-4 | 只有广告价值（内容流量 → 广告收入） |
| 0-1 | 无商业价值（纯学术、纯新闻） |

**检查方法**：
- 搜索结果中是否有付费广告？（有 = 有商业价值）
- 现有工具是否收费？收费多少？
- 用户是否在用手动方式解决这个问题？（= 自动化机会）
- 是否有 affiliate 产品推荐？（= 有转化路径）

### 6. 可执行性（Executability）

**问题**：以独立开发者的资源，能否快速做出内容或工具？

| 分数 | 标准 |
|---|---|
| 8-10 | 1-3 天可以做出内容页或简单工具 |
| 5-7 | 1-2 周可以做出有质量的页面或 MVP |
| 2-4 | 需要大量专业知识和时间（>1 个月） |
| 0-1 | 超出能力范围或需要大量资源 |

**检查方法**：
- 需要多少专业知识？是否在已有领域内？
- 技术复杂度：纯内容 vs 需要后端/数据库/API？
- 是否需要独家数据或合作关系？
- 能否基于现有模板或工具快速搭建？

### 7. 证据可信度（Evidence Quality）

**问题**：数据来自哪里？是实际搜索量还是推测？

| 分数 | 标准 |
|---|---|
| 8-10 | 有多个可靠来源的实际数据（Google Trends、Search Console） |
| 5-7 | 有间接证据（Autocomplete、社区讨论、竞品动作） |
| 2-4 | 只有单一来源或弱信号 |
| 0-1 | 纯推测，无实际证据 |

**证据分级**（从高到低）：
1. Google Search Console 实际数据（自己网站的）
2. Google Trends 数据（相对值，但可靠）
3. Ahrefs/Semrush 搜索量数据（付费工具，有误差）
4. Autocomplete + PAA 存在性（证明有查询，但不知量）
5. 社区讨论频率（间接信号）
6. 竞品动作（最弱信号）

**规则**：
- 没有实际搜索量数据时，标注"未核实"
- 不编造搜索量数字
- 证据不足时，评分上限为 5

## 评分汇总

```
总分 = (新颖性 + 增长性 + 搜索意图 + 竞争度 + 商业价值 + 可执行性 + 证据可信度) / 7 × 10
```

| 总分 | 分类 | 动作 |
|---|---|---|
| ≥ 70 | 立即执行 | 进入本周任务，分配具体动作 |
| 50-69 | 观察池 | 每周复查，等新证据 |
| < 50 | 归档 | 记录原因，不再跟踪 |

## 闸门规则

即使总分高，以下情况仍需降级：

- **证据可信度 < 5**：总分最高 60（证据不足不能盲目执行）
- **新颖性 ≤ 3 且竞争度 ≤ 3**：红海词，总分最高 50
- **搜索意图为导航类**：总分最高 40（属于其他品牌）
- **增长性 ≤ 3 且为下降趋势**：过时词，总分最高 40
