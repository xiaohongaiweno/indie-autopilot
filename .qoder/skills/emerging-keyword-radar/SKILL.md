# 新兴关键词雷达（Emerging Keyword Radar）

核心目标：尽早发现搜索中正在形成的新需求，判断哪些词值得做内容、工具或产品。

不追热词，追**有价值的词**。每个候选词必须经过七维评估才能进入执行。

## 铁律

1. **不编造搜索量。** 没有可靠数据源的搜索量一律标注"未核实"，不用记忆冒充实时数据。
2. **事实与推测分开。** 每条候选词标注【事实】【推测】【风险】，事实附来源链接。
3. **热源 ≠ 好词。** Product Hunt 热门、Twitter 热搜只说明"有人在说"，不说明"有人在做"。
4. **保守判断。** 宁可漏掉一个机会，不要把资源投到伪需求上。
5. **可执行才记录。** 每个候选词必须明确下一步动作：写文章、做页面、开发工具、还是继续观察。

## 五类关键词

| 类型 | 定义 | 重点信号 |
|---|---|---|
| 趋势上升词 | 搜索热度近期明显上升 | 搜索兴趣增长、持续时间、相关词扩散 |
| 新兴长尾词 | 新工具/功能/产品名、场景化问题词 | 自动补全、相关搜索、社区新表达 |
| 低竞争机会词 | 有需求但搜索结果质量差 | 结果相关性差、缺专门工具、现有页面体验差 |
| 新产品衍生词 | 围绕新产品/版本/功能形成的查询 | 教程、替代品、对比、使用方法查询出现 |
| 产品机会词 | 搜索词背后隐含明确任务需求 | 用户找解决方案、现有工具不足、仍依赖人工流程 |

## 七维评估框架

每个候选词必须检查：

| 维度 | 问题 | 评分 |
|---|---|---|
| 新颖性 | 以前没有，还是原本就存在的成熟词？ | 0-10 |
| 增长性 | 短期热点，还是持续上升？ | 0-10 |
| 搜索意图 | 了解、比较、下载，还是完成任务？ | 0-10 |
| 竞争度 | 搜索结果中是否有强势网站？ | 0-10（越高=竞争越低=越好） |
| 商业价值 | 有没有工具/产品/服务的切入点？ | 0-10 |
| 可执行性 | 能否快速制作内容页/工具页/MVP？ | 0-10 |
| 证据可信度 | 数据来自哪里，有实际搜索量还是推测？ | 0-10 |

总分 = 七维加权平均。≥70 立即执行；50-69 观察池；<50 归档。

## 工作流程

### 第一步：发现新词

从五个来源扫描，详见 `references/sources.md`：

1. **趋势数据**：Google Trends、Explore、Rising Queries
2. **搜索建议**：Google Autocomplete、Related Searches、People Also Ask
3. **社区讨论**：Reddit、Hacker News、V2EX、Twitter/X、Indie Hackers
4. **新产品发布**：Product Hunt、changelog、新版本公告
5. **竞品动态**：竞品新增页面、新内容方向、用户评价中的新需求

输出：10-20 个候选词，每个一句话说明"谁在搜什么、为什么现在出现"。

### 第二步：验证需求

逐个检查，详见 `references/evaluation-framework.md`：

- 搜索结果前 10 页：是否有高质量专门页面？
- 相关词和 People Also Ask：需求是否真实存在？
- 趋势历史：上升多久了？是周期性还是结构性？
- 搜索量证据：有数据就记录，没有就标注"未核实"

淘汰明显伪需求（纯新闻热点、无商业价值的八卦词）。

### 第三步：判断竞争

对通过验证的候选词做竞争分析：

- 现有页面质量：前 3 结果的内容深度、用户体验、更新频率
- 竞争对手：是谁在排名？大站还是小站？
- 内容缺口：现有页面缺少什么？用户还在找什么？
- 排名可行性：以独立开发者的资源，能否做出更好的页面？

### 第四步：分类机会

将候选词分为四类执行方向：

| 方向 | 适用场景 | 典型动作 |
|---|---|---|
| 写文章 | 信息类查询、教程需求 | 博客、指南、教程 |
| 做 SEO 页面 | 工具类查询、比较需求 | 落地页、对比页、工具页 |
| 开发在线工具 | 明确任务需求、现有工具不足 | 免费工具、MVP |
| 研究新产品 | 产品机会词、持续上升需求 | 验证实验、原型 |

### 第五步：持续追踪

记录到 `assets/keyword-tracker.md`：

- 发现日期
- 当前评分和分类
- 增长变化（周对比）
- 验证结果
- 实际效果（如果已执行）

每周或每次扫描时更新追踪记录，淘汰过期机会。

## 与其他 Skill 的关系

- `indie-product-radar`：更宏观的产品机会扫描，本 Skill 聚焦关键词层面的早期信号。
- `seo-opportunity-research`：分析已知关键词的 SEO 策略，本 Skill 负责**发现**新关键词。
- `indie-product-reach`：执行推广，本 Skill 的发现喂入其内容规划。
- `indie-builder-memory`：跨项目的关键词经验和验证结果沉淀。

## 输出格式

每次扫描输出 `assets/weekly-report.md`：

1. **本期发现**：Top 5-10 候选词，含七维评分和分类
2. **立即执行**：评分 ≥70 的词，附具体动作和预期产出
3. **观察池更新**：新增/升级/淘汰/过期的观察词
4. **已执行追踪**：上周期的词本周表现如何
5. **来源与证据**：所有数据来源和核验日期

参见 `references/sources.md`（数据源清单）、`references/evaluation-framework.md`（七维评估详解）。
