# Content and social distribution playbook

## Start with an audience problem
Choose one useful core asset: demo, tutorial, practical guide, comparison, founder lesson, or customer use case. Adapt it to platforms where the audience actually exists.

## Asset checklist
- Main audience and goal
- Hook/title options
- Platform-native copy or script
- Destination URL and CTA
- Screenshots/demo footage
- Captions/transcript and accessibility
- Thumbnail/cover concept
- Relevant platform requirements verified from current official sources
- Repurposing plan
- Measurement plan

## YouTube
Prepare a clear title, useful description, relevant links, chapters when helpful, accurate captions, thumbnail concept, and pinned comment draft. Use tags only when useful and do not rely on tags as a growth strategy by themselves.

## Social posts
Use native formats and platform norms. Avoid posting the exact same message everywhere. Do not use engagement bait, false claims, or unsolicited bulk DMs. Track links with consistent campaign parameters only when appropriate and privacy-conscious.
