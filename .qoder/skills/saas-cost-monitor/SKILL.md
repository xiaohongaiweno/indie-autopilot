# SaaS 成本监控

监控和优化 SaaS 产品的成本。核心问题：钱花在哪里？如何优化？如何保持健康的利润率？

## 铁律

1. **可见性优先。** 不知道钱花在哪里，就无法优化。
2. **定期审查。** 成本会随增长变化，需要定期审查。
3. **优化 ≠ 削减。** 优化是花得更聪明，不是花得更少。
4. **自动化监控。** 设置告警，不要等账单来了才发现。
5. **平衡成本和性能。** 不要为了省钱牺牲用户体验。

## 成本分类

### 固定成本
- **域名**：$10-$50/年
- **SSL 证书**：免费（Let's Encrypt）-$200/年
- **工具订阅**：开发工具、设计工具
- **专业服务**：会计、法律

### 可变成本（随用户增长）
- **托管平台**：Vercel、Railway、Fly.io
- **数据库**：Supabase、PlanetScale、MongoDB Atlas
- **CDN 和带宽**：Cloudflare、AWS CloudFront
- **邮件服务**：Resend、SendGrid
- **认证服务**：Clerk、Auth0
- **监控服务**：Sentry、Datadog
- **支付处理**：Stripe、Paddle（通常 2.9% + $0.30）

### 隐性成本
- **开发时间**：你的时间是最贵的
- **维护成本**：更新依赖、修复 bug
- **支持成本**：用户支持的时间
- **学习成本**：学习新技术的时间

## 成本监控

### 监控工具
- **平台原生**：Vercel Dashboard、AWS Cost Explorer
- **第三方**：CloudHealth、Spot.io
- **自建**：自定义脚本追踪成本

### 监控指标
- **总成本**：月度总成本
- **每用户成本**：总成本 / 用户数
- **成本增长率**：月环比增长
- **成本占收入比**：成本 / MRR

### 告警设置
- **预算告警**：超过预算 80% 时告警
- **异常告警**：成本突然增加时告警
- **增长告警**：成本增长快于收入时告警

## 成本优化策略

### 托管优化
- **选择合适的计划**：不要过度配置
- **使用免费层**：充分利用免费额度
- **自动扩展**：按需扩展，避免闲置
- **区域选择**：选择成本低的区域

### 数据库优化
- **查询优化**：优化慢查询
- **索引优化**：添加合适的索引
- **连接池**：复用数据库连接
- **缓存**：缓存频繁查询的数据

### CDN 和带宽优化
- **压缩资源**：Gzip、Brotli 压缩
- **图片优化**：WebP、适当大小
- **缓存策略**：合理的缓存时间
- **减少请求**：合并文件、懒加载

### 第三方服务优化
- **评估必要性**：真的需要这个服务吗？
- **比较价格**：有更便宜的替代品吗？
- **优化使用**：减少不必要的调用
- **自建替代**：高频使用的服务考虑自建

### 开发效率优化
- **自动化**：自动化重复任务
- **工具整合**：减少工具数量
- **开源替代**：用开源替代付费工具
- **批量处理**：批量处理减少 API 调用

## 成本基准

### 早期阶段（0-100 用户）
- **目标**：$0-$50/月
- **策略**：最大化免费层使用
- **常见成本**：
  - 托管：$0（Vercel free）
  - 数据库：$0（Supabase free）
  - 认证：$0（Clerk free）
  - 邮件：$0（Resend free）

### 增长阶段（100-1000 用户）
- **目标**：$100-$300/月
- **策略**：选择合适的付费计划
- **常见成本**：
  - 托管：$20-$50
  - 数据库：$25-$50
  - 认证：$0-$25
  - 邮件：$20-$50
  - 监控：$26-$50

### 规模化阶段（1000-10000 用户）
- **目标**：$500-$2000/月
- **策略**：优化单位成本
- **常见成本**：
  - 托管：$100-$500
  - 数据库：$100-$500
  - 认证：$50-$200
  - 邮件：$100-$300
  - 监控：$100-$300

## 成本健康指标

### 目标比率
- **成本占收入比**：< 30%（健康）
- **每用户成本**：持续下降
- **毛利率**：> 70%（SaaS 标准）

### 告警阈值
- **成本占收入比 > 50%**：需要优化
- **每用户成本上升**：需要调查
- **毛利率 < 60%**：需要紧急优化

## 工作流程

### 1. 成本可见性
- 列出所有成本项
- 分类（固定/可变）
- 追踪月度成本
- 计算关键比率

### 2. 成本分析
- 识别高成本项
- 分析成本趋势
- 比较行业标准
- 找到优化机会

### 3. 成本优化
- 优先级排序
- 实施优化
- 监控效果
- 持续迭代

### 4. 成本监控
- 设置告警
- 定期审查
- 预测成本
- 调整预算
