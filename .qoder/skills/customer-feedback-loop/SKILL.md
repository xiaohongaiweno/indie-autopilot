# 用户反馈循环

系统收集和响应用户反馈。核心问题：用户说什么？他们想要什么？如何转化为产品改进？

## 铁律

1. **主动收集。** 不要等用户来找你，主动询问。
2. **倾听 > 辩解。** 理解用户问题，不要急于解释。
3. **定量 + 定性。** 数据告诉你"什么"，访谈告诉你"为什么"。
4. **闭环反馈。** 让用户知道他们的反馈被听到了。
5. **优先行动。** 不是所有反馈都要实现，但要回应。

## 反馈收集渠道

### 产品内
- **反馈按钮**：随时可提交的反馈入口
- **NPS 调查**：定期询问推荐意愿
- **功能请求**：用户提交和投票功能请求
- **退出调查**：用户取消时询问原因

### 直接沟通
- **用户访谈**：1 对 1 深度访谈
- **用户测试**：观察用户使用产品
- **支持工单**：从支持请求中学习
- **社交媒体**：监控提及和评论

### 社区
- **论坛**：用户讨论和反馈
- **Reddit / HN**：社区讨论
- **用户群组**：微信群、Slack 群组
- **评价网站**：G2、Capterra、Product Hunt

## 反馈分类

### 按类型
- **Bug 报告**：功能不工作
- **功能请求**：想要新功能
- **改进建议**：现有功能如何改进
- **使用问题**：不知道怎么用
- **抱怨**：对某方面不满
- **赞扬**：喜欢某方面

### 按紧急程度
- **P0（立即处理）**：影响核心功能的 bug
- **P1（本周处理）**：重要 bug 或高频请求
- **P2（本月处理）**：改进建议
- **P3（Backlog）**：长期想法

### 按主题
- **功能**：特定功能的反馈
- **UX**：用户体验相关
- **性能**：速度、稳定性
- **定价**：定价相关
- **支持**：客户支持相关

## 工作流程

### 1. 收集反馈
- 设置反馈收集渠道
- 定期审查反馈来源
- 记录所有反馈
- 感谢用户提供反馈

### 2. 分类和标签
对每条反馈：
- 分类（类型、紧急程度、主题）
- 标签（相关功能、用户类型）
- 关联（链接到相关工单或请求）

### 3. 分析模式
- 识别高频问题
- 发现共同主题
- 量化影响（多少用户受影响？）
- 优先级排序

### 4. 响应反馈
- **Bug**：确认问题，提供时间线
- **功能请求**：解释优先级，提供替代方案
- **改进建议**：感谢，说明计划
- **抱怨**：道歉，解决问题

### 5. 转化为行动
- 高频 bug → 修复计划
- 高频请求 → 产品路线图
- 改进建议 → 优化计划
- 使用问题 → 文档改进

### 6. 闭环
- 通知用户反馈被采纳
- 发布更新时通知相关用户
- 感谢用户的贡献

## 用户访谈

### 访谈准备
- **明确目标**：想了解什么？
- **招募用户**：5-7 个目标用户
- **准备问题**：开放式问题
- **安排时间**：30-45 分钟

### 访谈问题示例
- 你用什么产品完成什么任务？
- 你最喜欢产品的什么？
- 你最不喜欢什么？
- 如果可以增加一个功能，会是什么？
- 你会推荐给朋友吗？为什么？
- 你用什么替代方案？

### 访谈技巧
- **多问为什么**：深入了解原因
- **倾听 > 说话**：让用户多说
- **避免引导**：不要引导用户给出你想要的答案
- **记录关键引用**：记录用户的原话

### 访谈后
- **整理笔记**：24 小时内整理
- **识别模式**：跨访谈找共同主题
- **分享洞察**：与团队分享
- **转化为行动**：形成具体任务

## NPS（净推荐值）

### 计算方法
- 询问：你有多大可能推荐我们的产品？（0-10）
- 推荐者（9-10）- 批评者（0-6）= NPS
- NPS 范围：-100 到 100

### NPS 解读
- **> 50**：优秀
- **20-50**：良好
- **0-20**：需要改进
- **< 0**：严重问题

### 跟进问题
- 推荐者：你最喜欢什么？
- 被动者（7-8）：如何改进？
- 批评者：主要问题是什么？

## 工具

### 反馈收集
- **Canny / UserVoice**：功能请求和投票
- **Typeform / Google Forms**：调查
- **Intercom / Drift**：产品内消息
- **Hotjar / FullStory**：用户行为

### 用户访谈
- **Calendly**：安排访谈
- **Zoom / Google Meet**：视频访谈
- **Otter.ai**：转录
- **Notion / Docs**：笔记

### 反馈管理
- **Linear / Jira**：工单管理
- **Notion / Airtable**：反馈数据库
- **ProductBoard**：产品管理

## 与其他 Skill 的关系

- `product-validation`：用户反馈验证需求
- `product-requirements`：反馈指导需求
- `product-analytics`：定量 + 定性分析
- `conversion-optimization`：反馈诊断转化问题
- `support-knowledge-base`：反馈改进支持
