# Launch day checklist

## Product:
## Launch date:
## Target platforms:

## 2 weeks before
- [ ] Landing page live with email signup
- [ ] Beta users recruited (10–50) and onboarded
- [ ] Product Hunt copy drafted (tagline, description, first comment, gallery)
- [ ] Hacker News Show HN post drafted
- [ ] Reddit posts drafted (2–3 subreddits, platform-specific)
- [ ] Launch email drafted and scheduled
- [ ] Twitter/X thread drafted
- [ ] Visual assets created (logo, screenshots, demo video/GIF)
- [ ] Open Graph tags added (og:title, og:description, og:image)
- [ ] Twitter Card tags added
- [ ] Analytics tracking configured (UTM parameters for each channel)
- [ ] Server capacity checked
- [ ] Support plan in place (who handles bugs/questions on launch day)

## 1 week before
- [ ] All copy finalized
- [ ] Beta feedback incorporated
- [ ] Launch date and time confirmed
- [ ] Social media posts scheduled or ready to publish
- [ ] Email scheduled or ready to send
- [ ] Final link check — all URLs work, forms submit correctly
- [ ] Pricing page live and accurate
- [ ] Documentation / help pages accessible
- [ ] Testimonials or beta user quotes ready to display

## Real-time monitoring

- [ ] Analytics dashboard open (traffic, signups, conversions)
- [ ] Product Hunt comments monitored (respond within 1 hour)
- [ ] Hacker News comments monitored
- [ ] Reddit comments monitored
- [ ] Twitter mentions and replies monitored
- [ ] Bug tracking — critical issues fixed immediately
- [ ] Server uptime monitored

## Post-launch (day 2–3)
- [ ] Share launch results publicly
- [ ] Answer follow-up questions from launch day
- [ ] Post user testimonials or feedback
- [ ] Publish launch retrospective (blog post or thread)
- [ ] Analyze which channels performed best
- [ ] Follow up with beta users and early adopters
